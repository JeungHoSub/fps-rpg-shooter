# 기획 v0.4 — 사용자 요구사항 (2026-11-18 플레이 피드백)

> 단계별(Phase)로 세션을 나눠 구현한다. 각 Phase 끝에 사용자가 유니티에서 확인 후 다음 Phase.
> 성능 기준: Intel HD 630 (CLAUDE.md 참고). 그래픽 품질 향상은 에셋 결정이 선행되어야 함.

## 1. 무기 구성 (슬롯)
| 키 | 슬롯 | 내용 |
|---|---|---|
| 1, 2 | 주무기 ×2 | 계열별 총기 |
| 3 | 보조무기 | 권총 |
| 4 | 근접 | 칼 등 (탄약 없음, 조용함 → 소리 시스템과 연계) |
| 5 | 특수 기기 | 투척 수류탄, 설치형 수류탄/지뢰, 설치형 기관총 등 |

## 2. 무기 계열 · 등급 · 강화
- **계열:** 소총, 산탄총, 저격총, 설치형 기관총, 화염방사기, 로켓·유탄(미사일탄), 권총, 근접
- 계열마다 **상위 총기**가 있고, **등급**(예: 일반 → 고급 → 희귀 → 영웅 → 전설)과 **강화**가 따로 있음
- **원칙:** 연사가 빠르고 탄창이 클수록 한 발 피해는 낮다 (DPS 예산 공식으로 밸런스)
- **망자 방어도**가 라운드마다 올라감 → 방어도가 높으면 관통/폭발/화염 계열이 유리
  → 모든 계열을 고르게 키워야 클리어가 쉬워지는 구조 (한 계열만 키우면 막힘)
- 무기마다 **고유 총성·타격음·반동·장전 동작**을 현실에 가깝게 (장전: 탄창 분리→삽입→노리쇠, 빈 탄창은 장전이 더 김)

## 3. 방어구 (1차)
모자 · 상의 · 하의 · 장갑 · 신발. 등급·강화 동일 체계. 이후 추가.

## 4. 소비 아이템
- 치료 키트 (사용 시간 있음)
- 스태미너 회복제 (달리기 게이지) → **스태미너 시스템** 필요

## 5. 능력치
- 시작 시 분배 + **레벨업마다 스탯 포인트**
- **몰빵 방지:** 모든 능력치가 유효하도록 수확 체감(투자할수록 효율 감소) + 능력치별 최소 요구(예: 무기 계열별 요구 스탯)

## 6. 라운드 룰
| 룰 | 클리어 조건 |
|---|---|
| **기본** | 기본 망자 → 엘리트 망자 → **보스 망자 처치 시 클리어** |
| **디펜스** | 제한 시간 동안 지점을 지켜냄 (망자가 지점에 닿으면 실패) |
| **미션** | 제한 시간 내 모든 망자 처치 |

- 라운드가 오를수록 기본 망자가 강해짐 (체력·방어도)
- **난이도 변형 (판마다 무작위 또는 단계별):** 탄약 감소, 주는 피해 감소, 체력 감소, 제한 시간 단축, 이동 속도 감소, 시야 감소(손전등 금지)

## 7. 망자 행동 (감지 AI)
- 기본 망자는 마을 곳곳에 **배치되어 배회/대기**
- **소리**(총성·달리기·장전)와 **빛**(손전등·총구 화염)에 반응해 달려듦
- 일정 시간이 지나면 **전부 플레이어에게 몰려옴**
- 손전등(F)을 켜면 시야는 좋아지지만 **멀리서 망자를 끌어들임** (위험 부담)

## 8. 망자 외형 — 킹덤 컨셉 (에셋 필요)
- 조선 역병 망자: 흰 소복/도포, 갓, 상투, 핏기 없는 피부, 하얗게 탁한 눈
- 현대 시골 망자: 작업복, 몸빼, 비옷
- 엘리트: 포졸, 무관(두정갑) / 보스: 대감(갓·도포), 무당
- **결정 필요:** 실사 에셋(구매 / Mixamo 무료 + 의상 별도) vs 저사양 분위기형

## 9. 배경 사실화
- 각진 도형 → 실제 모델(한옥·초가·장독대·정자·돌담·나무·가로등)
- **결정 필요:** 에셋 출처 (무료 저폴리 / 유료 팩 / 직접 제작 의뢰)
