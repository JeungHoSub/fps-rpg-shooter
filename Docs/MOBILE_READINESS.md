# 휴대폰 단계 준비 점검 (2026-11-22)

PC 방식으로 만든 기능들이 휴대폰(터치)에서 막히지 않는지 점검한 결과.

## 이번에 고친 것
- **앉기 버튼 추가** — 터치 조작에 앉기가 없었다 (`GameInput.touchCrouch`가 비어 있었음). 오른쪽 위 '앉기' 버튼, 누를 때마다 앉기/서기, 달리면 자동으로 일어섬.
- **능력 칸 겹침** — HUD 아래 능력·보급 칸(광폭·재생·청심·키트·회복)이 터치 버튼과 같은 일을 하며 왼쪽 조이스틱 자리와 겹침 → 터치 조작에서는 HUD 칸을 숨김.
- **앉기 표시·보급품 알림** — 터치 조작에서는 왼쪽 위로 옮김 (조이스틱·광폭/재생 버튼 피함).

## 이미 괜찮은 것
- 모든 게임 입력이 `GameInput`을 거친다 (직접 키 읽기는 F9 판정 보기 디버그뿐).
- 서낭당·시작·사망 화면 버튼은 IMGUI 버튼 → 손가락 터치가 마우스로 들어와 그대로 눌린다.
- 조작 안내(TutorialHints)는 키보드 전용이라 터치에서는 띄우지 않음.

## 휴대폰 단계에서 할 일 (사용자와 논의됨)
1. 달리기 고정 — 조이스틱을 위로 끝까지 밀면 손을 떼도 계속 달림
2. 자이로 조준 — 폰을 기울여 미세 조준 (설정에서 켜고 끄기)
3. 왼쪽 사격 버튼 — 왼손 엄지로도 쏠 수 있게
4. 조이스틱 크기·투명도 설정
5. 터치용 조작 안내 (버튼 위치를 손가락 그림으로)
6. 서낭당 화면 글씨·버튼 크기를 휴대폰 화면에 맞게 키우기
7. PC에만 있는 새 조작을 터치 버튼으로: 돌·폭죽 던지기(B, `GameInput.StoneDown`), 지도(M), 발차기(달리며 칼 — 터치 칼 버튼으로 이미 됨), 앉기 전환식은 터치 앉기 버튼이 이미 전환식
8. 확성기 탑·장승·보급 상자·기관총 거두기: 터치에선 'E' 대신 화면 버튼 하나(`GameInput.PickupDown` 터치판)

## 성능 주의 (휴대폰 '하' 품질)
- 망자 모델(Romero) 약 2.5만 정점 → '하'는 동시 10마리, 비상 절약 모드는 7마리.
- 총 모델: M4A1 1만 정점(가장 무거움), 나머지 1~5천 → 문제없을 것으로 봄.
- 피 웅덩이 최대 18개, 살점 '하' 3개 — 반투명 겹침이 많으면 휴대폰 GPU 부담 → 실제 기기에서 확인 필요.
- 실기기 시험은 Hunt → 안드로이드 APK 메뉴로 빌드 후 폰에서 확인해야 함 (클라우드에선 불가).
