# 1인칭 RPG 슈터 — 기획 초안 v0.1

> 가제: **PROJECT: HUNT** (컨셉 확정 후 변경)
> 장르: 1인칭 협동 PvE 슈터 + RPG 성장
> 모티브: 카운터스트라이크 온라인 좀비 모드 (웨이브 생존, 영웅/숙주 개념)
> 적: 괴물 (세계관/컨셉에 따라 교체 가능하도록 "적 데이터"는 컨셉과 분리 설계)

---

## 1. 핵심 한 줄

**"총을 쏘는 손맛은 FPS, 강해지는 재미는 RPG — 그리고 괴물은 우리가 쓰는 전략에 맞춰 진화한다."**

---

## 2. 기본 게임 루프

```
[로비] 캐릭터·무기 세팅
   ↓
[매치] 웨이브 1 → 2 → ... → 보스 웨이브   (1매치 15~20분)
   │   ├ 웨이브 중: 사격 / 스킬 / 약점 공략
   │   └ 웨이브 사이(30초): 매치 내 레벨업 퍽 선택, 상점, 바리케이드 설치
   ↓
[정산] 경험치, 골드, 몬스터 재료, 무기 파츠 드랍
   ↓
[성장] 캐릭터 레벨/스탯, 무기 강화·파츠 장착 → 다시 매치
```

- **매치 내 성장** (판마다 리셋): 웨이브 클리어 시 레벨업 → 3개 퍽 중 1개 선택 (로그라이트식)
- **영구 성장** (계정/캐릭터): 레벨, 스탯 포인트, 무기 강화, 파츠 수집

## 3. 캐릭터 스탯 설계

### 3-1. 기본 스탯 (포인트 투자형)

| 스탯 | 효과 | 비고 |
|---|---|---|
| **힘 (STR)** | 최대 소지 무게 ↑, 무거운 무기 페널티 ↓, 근접 데미지 ↑ | 무게 시스템과 연동 |
| **민첩 (AGI)** | 이동속도, 재장전 속도, 무기 교체 속도 ↑ | |
| **제어 (CTL)** | 반동 감소, 탄퍼짐 감소, 조준(ADS) 속도 ↑ | **FPS 실력 + 스탯의 접점** |
| **체력 (VIT)** | 최대 HP, 방어력, 상태이상 저항 ↑ | |
| **집중 (FOC)** | 치명타 확률, 약점 데미지 배율 ↑ | |
| **기술 (TEC)** | 스킬 쿨다운 ↓, 스킬 위력 ↑, 장비(포탑 등) 성능 ↑ | |

### 3-2. 캐릭터(클래스) 예시 — 같은 레벨이어도 기본 스탯·성장률·고유 스킬이 다름

| 캐릭터 | 역할 | 강한 스탯 | 고유 패시브 | 액티브 스킬 |
|---|---|---|---|---|
| **브루저** | 탱커 | STR, VIT | 근접 처치 시 HP 회복 | 도발 함성 (주변 괴물 어그로) |
| **스카우트** | 기동 딜러 | AGI, FOC | 이동 중 사격 정확도 패널티 없음 | 대시 + 다음 탄 치명타 확정 |
| **마크스맨** | 저격 딜러 | CTL, FOC | 정지 상태 2초 시 약점 데미지 +50% | 약점 투시 (5초) |
| **엔지니어** | 서포터 | TEC, VIT | 바리케이드 내구도 2배 | 자동 포탑 설치 |
| **메딕** | 힐러 | TEC, AGI | 아군 근처에서 재장전 속도 ↑ | 치유 수류탄 |

### 3-3. 무게 시스템
- 각 무기는 **무게**를 가짐. `총 장비 무게 > STR 기반 허용치` 이면 이동속도·ADS 속도 감소
- → 힘캐는 경기관총+샷건 같은 무거운 조합 가능, 민첩캐는 가벼운 SMG 위주

## 4. 무기 시스템

### 4-1. 무기 스탯

| 스탯 | 설명 |
|---|---|
| 데미지 | 1발당 기본 피해 |
| 연사 속도 (RPM) | 분당 발사 수 |
| 탄창 / 예비탄 | 장탄 수, 최대 휴대 탄약 |
| 재장전 시간 | 일반 / 빈 탄창(택티컬·엠티) 분리 |
| 반동 패턴 | 수직·수평 반동 + **고정 패턴** (배울 수 있는 반동) |
| 탄퍼짐 | 지향사격 / 조준 / 이동 중 각각 |
| 유효 사거리 | 사거리 밖에서 데미지 감소 곡선 |
| 관통력 | 몬스터 여러 마리·장갑 관통 |
| **넉백 (저지력)** | 괴물을 밀어내는 힘 — **좀비 모드의 핵심 손맛** |
| 무게 | 3-3 무게 시스템 연동 |
| 속성 | 물리 / 화염 / 냉기 / 전기 / 독 |

### 4-2. 무기 종류 예시

| 분류 | 특징 | 예시 수치 (데미지/RPM/탄창/넉백) |
|---|---|---|
| 권총 | 가볍고 빠른 교체 | 30 / 400 / 12 / 낮음 |
| SMG | 근거리 고연사, 반동 적음 | 22 / 900 / 35 / 낮음 |
| 돌격소총 | 범용 | 34 / 650 / 30 / 중간 |
| 샷건 | 근거리 폭딜, 넉백 최강 | 15×9 / 70 / 8 / 매우 높음 |
| 저격총 | 약점 일격, 관통 | 180 / 40 / 5 / 중간 |
| 경기관총 | 대용량, 무거움, 반동 큼 | 30 / 750 / 100 / 높음 |
| 특수 | 화염방사기, 레일건, 석궁 등 | 무기별 |

### 4-3. 데미지 공식 (초안)

```
최종 데미지 = 무기 데미지
            × (1 + 강화 보너스)
            × 부위 배율        (일반 1.0 / 머리 2.0 / 약점 3.0 + FOC 보너스)
            × 속성 상성        (괴물별 0.5 ~ 1.5)
            × 거리 감쇠
            × 치명타 배율      (발동 시 1.5 + 보너스)
            − 괴물 방어력       (관통력으로 일부 무시)
```

## 5. 괴물 설계

| 유형 | 역할 | 특징 |
|---|---|---|
| 러너 | 기본 잡몹 | 빠르고 약함, 떼로 몰려옴 |
| 브루트 | 탱커 | 앞면 장갑, **등 약점** |
| 스피터 | 원거리 | 산성 투사체, 장판 생성 |
| 점퍼 | 기습 | 벽 타고 위에서 덮침 |
| 버서커 | 엘리트 | 체력 50% 이하 시 광폭화 |
| 보스 | 최종 웨이브 | 부위 파괴, 페이즈 전환 |

※ 괴물 데이터(외형/이름)와 행동 데이터(AI/스탯)를 분리 → 나중에 컨셉이 바뀌어도 외형만 교체

## 6. ⭐ 기존 게임과 다르게 할 요소 (차별화 후보)

카스온라인 좀비 모드 및 일반 RPG 슈터와 차별화할 아이디어들. **전부 넣을 필요 없고 2~3개를 핵심으로 고르는 게 좋습니다.**

### A. 적응형 진화 괴물 시스템 ★추천
- 팀이 이번 매치에서 많이 쓴 **속성/무기 타입/공격 부위**를 집계
- 다음 웨이브 괴물이 그에 대한 **내성을 얻으며 진화** (예: 헤드샷이 많으면 머리에 장갑 생성, 화염을 많이 쓰면 화염 저항 변이)
- 효과: "한 무기만 들고 반복" 패턴 파괴, 무기 교체·팀 조합 이유 생성
- 진화한 괴물을 처치하면 희귀 재료 드랍 → 보상과도 연결

### B. 감염 게이지 — "괴물의 힘을 빌린다" ★추천
- 카스 좀비 모드의 "감염" 개념을 **플레이어 리소스로 재해석**
- 괴물에게 피격되면 감염 게이지가 쌓임
- 게이지를 소모해 **일시적 변이 능력** 사용 (괴력, 벽 타기, 재생 등)
- 100% 도달 시 일정 시간 **통제 불능 상태**(아군 공격 X, 시야 왜곡, 조작 페널티) → 아군이 치료해야 함
- 리스크/리턴: "일부러 맞아서 강해질 것인가?"

### C. 스탯이 반동을 "줄이는" 게 아니라 "바꾸는" 시스템
- 일반 RPG 슈터: 스탯 올리면 반동이 그냥 작아짐 → 실력 의미 감소
- 여기서는: CTL 스탯이 **반동 패턴을 더 예측 가능하게** 만들고 회복 속도를 올림
- 실력 좋은 유저는 낮은 스탯으로도 제어 가능 → **FPS 실력과 RPG 성장이 서로를 대체하지 않고 보완**

### D. 무기 파츠 + 랜덤 옵션 (핵앤슬래시 파밍)
- 총열·탄창·개머리판·조준경·총구·특수 모듈 슬롯
- 파츠마다 랜덤 옵션 (예: "재장전 후 첫 3발 데미지 +40%", "약점 명중 시 탄약 1발 회복")
- **같은 AK라도 사람마다 다른 총** → 파밍 동기 + 빌드 연구

### E. 부위 파괴 & 동적 약점
- 괴물마다 약점 위치가 다름 (머리가 아닐 수 있음)
- 장갑을 파괴해야 약점 노출, 다리를 부수면 이동 불가
- 보스는 페이즈마다 약점 위치 이동
- → "헤드만 쏘면 끝"인 기존 공식 탈피, 역할 분담 (장갑 깨는 샷건 / 약점 노리는 저격)

### F. 웨이브 사이 거점 운영 (짧은 타워디펜스 요소)
- 30초 휴식 동안 바리케이드·지뢰·포탑 설치, 탄약 보급
- 맵 구조를 팀이 바꿔가며 방어선 구축 → 매번 다른 공략

### G. 매치 내 로그라이트 퍽
- 웨이브마다 3택 1 퍽 (예: "샷건 펠릿이 튕김", "처치 시 폭발")
- 퍽 조합 시너지 → 판마다 다른 플레이 경험, 영구 성장과 별개로 매판 새로운 재미

### H. 역할 시너지 콤보
- 속성 상태이상 조합 (냉기로 얼린 적 + 물리 타격 = 파쇄 / 독 + 화염 = 폭발)
- 다른 캐릭터끼리 협동 시 추가 효과 → 혼자보다 팀이 강한 구조

## 7. 추천 핵심 조합

| 조합 | 정체성 |
|---|---|
| **A + B + E** | "진화하는 괴물과 싸우며, 나도 괴물이 되어가는" 생존 슈터 — 스토리·컨셉 색이 강함 |
| **D + G + C** | "파밍과 빌드 연구"의 루트슈터 — 장기 운영·재플레이성 강함 |
| **E + F + H** | "팀 전술" 중심 협동 디펜스 — 친구끼리 하기 좋음 |

개인 추천: **A(진화) + B(감염 게이지) + D(파츠 파밍)** — 카스 좀비 모드의 감성(감염)을 계승하면서, 반복 플레이 동기(파밍)와 매판 변화(진화)를 동시에 확보

## 8. MVP (첫 프로토타입) 범위 제안

1. 1인칭 이동/사격/재장전/ADS
2. 무기 3종 (돌격소총, 샷건, 권총) — 스탯 데이터 기반
3. 캐릭터 2종 (브루저, 마크스맨) — 스탯 차이 확인
4. 괴물 2종 (러너, 브루트) + 부위 판정 (머리/약점/일반)
5. 웨이브 5개 + 간단한 보스 1
6. 데미지 공식 + 데미지 숫자 표시
7. 차별화 요소 1개 시범 적용 (추천: A 적응형 진화)
