# 컨셉 v0.3 — 역병의 마을 (가제)

> 1인칭 싱글플레이 · 직업 없음(스탯 + 특성) · 웨이브 생존 + RPG 성장
> 이 문서는 [GAME_DESIGN_DRAFT.md](GAME_DESIGN_DRAFT.md)의 시스템(A~E)에 **세계관과 분위기**를 입힌다.

## 1. 한 줄 컨셉

**"비가 그치지 않는 산골 마을. 조선 때 봉인된 역병이 깨어나, 오늘의 마을 사람들과 무덤 속 옛 망자가 함께 걸어 나온다."**

## 2. 분위기

| 요소 | 방향 |
|---|---|
| 날씨 | 추적추적 내리는 비, 낮게 깔린 안개, 젖은 흙길과 웅덩이에 비친 가로등 |
| 빛 | 전체적으로 어둡다. 가로등, 비닐하우스 백열등, 손전등, 총구 화염이 주요 광원 |
| 소리 | 빗소리가 기본으로 깔림. 개 짖는 소리, 확성기 잡음, 멀리서 나는 징소리, 좀비의 그르렁거림 |
| 색 | 먹색(검정), 젖은 녹색(논·대나무), 바랜 한지색, 핏빛 진홍, 낡은 금색 |
| UI | 먹과 한지 질감, 핏빛 진홍 포인트, 낡은 금 테두리, 세리프(바탕체) 제목 |

## 3. 배경: 현대 시골 + 조선 역병

- **장소:** 산으로 둘러싸인 한국 시골 마을
  - 논두렁과 비닐하우스
  - 마을회관과 확성기 탑
  - 폐교, 버스 정류장, 정자나무
  - 장승과 서낭당
  - 산 아래 공동묘지와 오래된 무덤
- **사건:** 산사태로 조선 시대 역병 무덤(봉인된 고분)이 무너짐 → 비를 타고 역병이 번짐
- **주인공 '헌터':** 마을에 홀로 남은 생존자. 현대 총기를 쓰면서 무당이 남긴 부적과 굿의 힘을 빌린다.

## 5. 혼합 시스템

### 5-1. 소리에 모이는 좀비 + 빗소리
- 총성, 발소리, 달리기, 재장전은 **소음**을 낸다 → 반경 안의 좀비가 소음 위치로 모여든다
- **빗소리**가 강해지는 구간에서는 소음 반경이 줄어든다 → 그 틈에 조용히 움직일 수 있음
- 소음기 파츠(총구)와 "고요한 걸음" 계열 특성의 가치가 오른다
- 혼자 하는 긴장감: 쏠지, 피해서 지나갈지 선택하게 됨

### 5-2. 오행(五行) 속성 — 기존 5속성 대체

| 기존 | 오행 | 연출 |
|---|---|---|
| 물리 | **금(金)** | 쇠붙이 탄환 |
| 화염 | **화(火)** | 불, 화상 |
| 냉기 | **수(水)** | 차가운 물, 둔화 |
| 전기 | **목(木)** | 벼락(震), 연쇄 |
| 독 | **토(土)** | 썩은 흙, 중독 |

- **상극(相剋):** 목→토→수→화→금→목. 상극 속성으로 치면 피해 +50%, 반대 방향은 피해 −30%
- **상생(相生):** 목→화→토→금→수→목. 상생 순서대로 속성을 바꿔 맞히면 **연쇄 보너스**
- 좀비마다 오행 기운이 있다 (예: 물에 불은 익사체 = 수(水) → 토(土) 탄환이 약점)
- **진화 시스템(A)과 연결:** 많이 맞은 속성에 적응한다. 그 속성을 극하는 오행으로 바꿔야 한다는 순환 압박이 생김

### 5-3. 밤낮 순환
- **밤 = 웨이브.** 비가 세지고 좀비가 날뛴다 (기존 웨이브)
- **낮 = 정비 시간.** 좀비는 그늘(헛간, 비닐하우스, 폐교)에 숨는다
  - 마을을 탐색해 탄약, 파츠, 부적을 줍는다 (기존 30초 정비를 탐색 시간으로 확장)
  - 숨은 좀비를 건드리면 낮에도 싸움이 벌어짐 (위험과 보상)
- 밤이 거듭될수록 비가 거세지고 진화 세대가 오른다

## 7. 구현 로드맵

1. **UI 전면 개편** — 한국 호러 톤 (진행 중)
2. **분위기** — 비 파티클, 빗소리, 어둠과 안개, 손전등, 가로등
3. **맵** — 시골 마을 블록아웃: 논, 비닐하우스, 마을회관, 장승, 무덤
4. **좀비 외형** — 현대 주민 / 조선 망자 프리미티브 외형 (MonsterFactory 교체)
5. **소리 시스템** — 소음 전파와 빗소리 마스킹
6. **오행** — 속성명 교체, 상극·상생, 좀비 오행 기운
7. **밤낮 순환** — 낮 탐색과 밤 웨이브
